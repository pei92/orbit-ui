使用指南

Orbit UI 是一个 Skill：装进 Agent 之后，你照常用自然语言提需求，它会按这套方法工作。你也可以单独使用里面的 orbit.css 和工具脚本。

01安装

推荐用 skills 命令安装，也可以让 Agent 替你执行：

npx skills add pei92/orbit-ui

或者手动把仓库复制到 Agent 的 Skill 目录。以 Claude Code 为例：

# macOS / Linux
git clone https://github.com/pei92/orbit-ui ~/.claude/skills/orbit-ui

# Windows（PowerShell）
git clone https://github.com/pei92/orbit-ui $HOME\.claude\skills\orbit-ui

不需要额外配置。对比页生成器需要 Python 3.10+，截图工具需要 Node 22+ 和本机的 Chrome 或 Edge；没有它们时 Skill 仍然可用，只是少了这两个工具。

02怎么对 Agent 说

直接描述产品和你要的东西，不需要提 Skill 的名字。这些说法都会触发它：

给我们的卫星遥测平台设计首页，要有太空科技感。
做三种风格差异明显的发射直播页，放进对比页让我选。
外卖订单追踪页太普通了，用 orbit-ui 的方式加一点太空感，别影响下单流程。
参考 Starfield 的界面，帮我做一个智能家居控制面板。
只评审这个运营看板，给出修改建议，不要改文件。

说得越具体，越少来回：谁在用、首屏要让人做什么、有哪些真实数据、在什么设备上看。不想参与选择时，说“你定”或“直接做”，Agent 会自己选方向并写明理由。

03一次完整的流程

  1. 认品类、拆标杆Agent 找同类里两三家风格最鲜明的产品，拆出控件、字体、颜色、数据呈现等要素
  2. 用文字写出三个方向每个方向三四行，附推荐和理由。这一轮到此结束，等你回复
  3. 你来选回复“按第二个做”，或者“三个都做成首屏我看看”
  4. 做出完整页面，对着截图打磨桌面和手机各截一张，修对比度、细线、换行
  5. 评审、做减法、交付交付说明写清方向、改动、删掉的装饰和截图位置

小改动（“这个按钮换成琥珀色”）不走这套流程，Agent 直接改，在目标视口看一眼就交。

04选方向

四个方向各有一套色板，都写在 orbit.css 里。方向谱里还有全息 HUD、太空竞赛复古、舱内材质、地球观测，Agent 会按产品挑选。

方向北极星适合
任务控制台 mission盯着唯一一个会决定结果的数字看板、监控、运动数据、交易终端
轨道蓝图 blueprint把东西画成工程图纸，读懂它3C / 家居商品页、产品说明、功能介绍
深空 deepfield安静到只剩一束光金融账户、会员中心、品牌首页
星际拓荒 frontier舷窗边打开任务日志（参考 Starfield）订单追踪、智能家居、出行、游戏化任务

05使用 orbit.css

不经过 Agent 也能直接用。把 assets/orbit.css 复制到项目里，在 <html> 上选一个方向：

<html lang="zh-CN" data-orbit="frontier">
<link rel="stylesheet" href="orbit.css">

<button class="o-btn o-btn--primary"><span class="o-key">E</span>采集样本</button>
<span class="o-status o-status--warn">一级液氧补加中</span>
<div class="o-arc" style="--v:72">…</div>

常用类名

类名用途
.o-btn --primary --danger按钮；aria-busy="true" 显示处理中
.o-input输入框；aria-invalid="true" 显示错误
.o-status--nominal / --warn / --alert状态灯：形状 + 颜色 + 文字，不只靠颜色
.o-arc（--v、--size）刻度环，圆心放读数
.o-gauge（--v）刻度条
.o-list（aria-current）菜单，选中整行反白
.o-tabs（aria-selected）胶囊分段
.o-track / .o-objectives订单、物流、任务进度
.o-table（数字列 .num）表格，数字右对齐、等宽
.o-switch / .o-avatar / .o-key开关、头像、按键提示
.o-panel / .o-rule / .o-stripe / .o-grid-bg面板、带端点的分区线、涂装条、坐标网格

完整控件和四套色板的效果：控件总览页（地址加 ?orbit=frontier 可直接切换色板）。

06风格对比页

在一个目录里放 manifest.json 和每个方向的 HTML，运行生成器，得到一个可以离线打开的单文件对比页：

python scripts/build_explorer.py examples/launch-page/manifest.json --force
{
  "schemaVersion": 1,
  "project": "星砚航天 XY-07 发射页",
  "brief": "首屏让访客知道何时发射、能否观看，并订阅提醒",
  "round": "01",
  "candidates": [{
    "id": "frontier", "name": "星际拓荒",
    "concept": "像在飞船舷窗边打开任务日志",
    "typography": "Jost 300 / Barlow",
    "palette": ["#0b0d10", "#eceae2", "#ec7d2a"],
    "traits": ["星球占半屏", "刻度环倒计时"],
    "source": "frontier.html"
  }]
}

候选引用的本地 CSS、图片、字体会被内嵌进对比页。写错时生成器会一次列出所有要改的地方。在对比页里点“选择”，会复制一句“第 01 轮：选 04 星际拓荒”，发回给 Agent 即可。

07截图检查

不需要安装 npm 依赖，直接调用本机的 Chrome / Edge，用 DevTools 协议精确模拟手机视口：

# 桌面 1440×900 和手机 390×844 各一张，输出到 shots/
node scripts/shoot.mjs examples/scenarios/delivery.html --size both

# 长图；本地文件也可以带地址参数
node scripts/shoot.mjs "examples/components.html?orbit=deepfield" --size desktop --full

找不到浏览器时，设置环境变量 ORBIT_CHROME 指向浏览器的可执行文件。截图保存成功不等于看过：Agent 会用看图能力逐张检查。

08日常业务

用户要的常常不是太空产品，而是“让外卖 App 有点太空感”。这时太空是语言，不是题材。Agent 会先把业务对象翻译成仪器，再决定剂量：

业务对象对应成控件
订单 / 物流进度任务阶段、检查点.o-track
地图路线、骑手轨道与卫星SVG 路线 + 引线标注
剩余时间倒计时.o-arc
余额、营业额主读数大号 tabular 数字
房间、门店舱段 / 舰队.o-list 反白选中
商品卖点工程图纸标注引线 + 尺寸线

不能变的东西：主操作一次可达；金额和时间按本地习惯写（“18:42 送达”，不写 UTC）；可读性优先于氛围。

10常见问题

我的品牌是浅色的，也能用吗？

能。太空不等于黑底。可以用轨道蓝图的线条语言配浅底，或者只借控件语法和数字字体，不改品牌色。

为什么 Agent 先发文字，不直接做页面？

做三个完整首屏很贵，而大多数时候你从文字里就能选出方向。你说“三个都做成首屏”，它才会做对比页。

星际拓荒方向会用 Starfield 的素材吗？

不会。只借用它的设计语言（反白选中、带端点的线、刻度环、涂装条），不使用原作的标志、徽章、专有字体和截图。

可以只用 orbit.css，不装 Skill 吗？

可以。它是一个普通的 CSS 文件，没有构建步骤，复制进项目即可。

网站里的案例和仓库里的示例会不一致吗？

不会。网站在 dist/ 里由 python scripts/build_site.py 生成：每次都从 website/、最新的 orbit.css 和 examples/ 整体重建。
