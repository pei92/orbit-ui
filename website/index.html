Orbit UI 是给 AI Agent 用的界面设计 Skill。它不再交出“黑底 + 霓虹青 + 粒子”，而是先拉开几个真正不同的太空科技方向让你挑，再对着真实截图打磨。

为什么需要它

“科技感”不是一组特效

让模型做“太空科技风”，十次里有九次是同一张脸。Orbit UI 把这个模糊的词翻译成能检查的设计决定。

模型的默认

  • 全屏粒子星空 + 居中大标题 + 两个按钮
  • 霓虹青发光描边，每张卡片都发光
  • Orbitron 字体铺满全站
  • “99.9% 可靠性”这类空洞的假数据

Orbit UI 的做法

  • 先认品类、拆标杆，再挑三个真正不同的方向
  • 发光只给正在发生的信号和唯一的主动作
  • 等宽数字承担数据，正文用好读的字
  • 412.6 km、T−00:04:37、238 ms 这样真的数
原则 01仪器的诚实

每条线都在测量什么，每处光都来自一个真实的信号。说不出它测量什么的装饰，删掉。

原则 02方向真的不同

骨架、字体、色彩、主视觉四项里，任意两个方向最多一项相同。

原则 03只在一两处极致

倒计时归零、读数刷新、指令回显。全页装饰语言最多两种，其余保持安静。

工作流程

先用文字问你，再动手

Agent 按这五步走。方向没定之前，不写一行页面代码。

  1. 认品类拆标杆

    找同类里风格最鲜明的两三家，拆出看得见的要素，决定留什么、换什么。

  2. 写方向三个方向问你

    每个方向三四行：感觉、首屏、字体色彩、主视觉，附推荐理由。

  3. 对比页并排挑选

    想看画面时做成三张首屏，放进对比页，点“选择”把结果发回给 Agent。

  4. 制作对着截图打磨

    桌面和手机各截一张，查对比度、细线、等宽数字和中文换行。

  5. 交付做减法

    每屏一个主角，删掉多余装饰；交付说明写清改了什么、删了什么。

不只是太空

外卖、钱包、后台，也能有太空感

把业务对象翻译成仪器：订单是任务，路线是轨道，余额是主读数，房间是舱段。只在说得通的地方用。

外卖订单追踪配送路线 = 轨道 · 送达时间 = 刻度环
个人账户余额 = 深空里唯一的亮星
