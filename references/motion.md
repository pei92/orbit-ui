# 动效

太空界面的动效来自两种真实的节奏：**仪器刷新**（快、离散、只动变化的部分）和**天体运动**（慢、连续、不打断阅读）。不要把两种节奏混在同一个元素上。

## 三处基本动效

每个新界面至少做出这三处，并让它们用同一组缓动和时长（`--o-ease`、`--o-fast`、`--o-slow`）：

1. **进入**：面板自左向右“上电”（`clip-path: inset` 展开），同屏依次延迟 40–80ms。只在首次加载时播放。
2. **反馈**：按钮按下下沉 1px；处理中底部扫描条；完成后回显结果（ACK / 延迟毫秒数）。
3. **数据变化**：等宽数字只让变化的那一位滚动或闪一下；刻度条宽度用 `--o-slow` 过渡。

## 天体运动

- 星空：用 Canvas 画 2–3 层不同速度的星点做视差，星点数量按面积算（约每 8000px² 一颗）；静止时不闪烁，闪烁只给一两颗“信号星”。
- 轨道：SVG `stroke-dasharray` + `stroke-dashoffset` 画出轨迹，卫星标记沿 `offset-path` 移动；一圈 20 秒以上，慢到不抢注意力。
- 行星自转：贴图横向平移或 three.js 旋转，周期 60 秒以上。

## 启动序列（首屏动画）

发布页和直播页可以做一段 1.5 秒以内的启动序列：网格淡入 → 主读数逐位落定 → 主按钮最后出现。必须可以跳过，第二次访问不再播放（用 `sessionStorage` 记录，读写包 try/catch）。

## 滚动叙事

落地页、发布页适合一段滑动驱动的叙事：

- **发射**：滚动推进倒计时与高度读数，火箭画面上移，背景从大气蓝过渡到太空黑。
- **入轨**：滚动时视角从地面拉远，地球边缘出现，轨迹线随滚动绘制。
- **深场**：滚动放大一张深空照片，逐层显示标注。

用 GSAP ScrollTrigger 或 CSS `animation-timeline: scroll()`（注意兼容性）实现，不手写滚动事件节流。

## 检查

- `prefers-reduced-motion: reduce` 下关闭所有循环动画，保留状态变化。
- 告警闪烁频率不超过每秒 3 次。
- 录一段屏按正常速度看一遍：该动的没动就补，动得抢了主读数的就减。
