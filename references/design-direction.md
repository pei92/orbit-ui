方向的目标是“这个品类里最好的团队会这样做，而且做出了这个产品自己的样子”。太空题材最容易滑进同一个默认：黑底、青色霓虹、发光描边、粒子背景、Orbitron 字体。这不是方向，是模板。

## 认品类，拆标杆

1. **说出品类和标杆。** 航天公司官网（SpaceX、Rocket Lab、Blue Origin）、地球观测数据平台（Planet、Maxar、Sentinel Hub）、任务可视化（NASA Eyes、ESA Mission Control）、发射直播、科幻游戏 HUD（Elite Dangerous、Destiny）、电影界面（《星际穿越》《火星救援》《异星灾变》的 Territory Studio 作品）。选风格最鲜明的两三家。
2. **拿到真实画面再拆。** 用宿主的浏览器取到首屏和一个关键控件的画面，拆成 6–10 条看得见的要素：控件形状、字体、颜色、数据怎么摆、状态怎么表达、动效、文案语气。拿不到画面时在方向卡写明“未看图，凭记忆”。
3. **决定留什么、换什么。** 理由在本产品里同样成立的留下，不成立的换掉。

分清三样东西：

- **基线**：用户已经期待的结构，例如直播页倒计时在首屏正中、数据平台左侧是图层、右侧是地图。
- **套路**：人人都在用的默认版式，例如“全屏星空 + 居中大标题 + 两个按钮”。一轮方向里至少一个要打破它。
- **撞脸**：字体、配色、主视觉都和某个标杆一样。任何方向都不允许。

## 定调性

| 刻度 | 两端 | 在太空界面里看什么 |
| --- | --- | --- |
| 能量 | 安静 ↔ 喧闹 | 发光强度、动效频率、告警色面积 |
| 完成度 | 粗粝 ↔ 精致 | CRT 颗粒、扫描线 ↔ 亚像素细线、精确网格 |
| 密度 | 疏 ↔ 密 | 深空留白 ↔ 满屏遥测 |
| 分量 | 轻 ↔ 重 | 细线与细字 ↔ 实心色块与粗等宽字 |
| 严肃度 | 活泼 ↔ 庄重 | 游戏化 HUD ↔ 真实任务控制 |

取值写成“这个产品是什么 → 五个刻度各取哪一端”，依据来自它的受众和使用场合。卫星运维工具和太空主题手游可以都叫“太空科技感”，调性几乎相反。

### “科技感”必须翻译

| 模糊词 | 翻译成可观察的决定 |
| --- | --- |
| 科技感 | 等宽数字承担主信息；每条线都对应坐标、刻度或分区；状态有三重表达 |
| 未来感 | 去掉拟物和阴影，层级靠线的强弱和底色微差；一处非常规构图（环形、斜切、超大数字） |
| 高级 | 一种强调色，面积不超过 5%；字号层级拉大；装饰语言不超过两种 |
| 震撼 | 首屏一个占半屏以上的主视觉（行星边缘、轨迹、发射画面），其余元素让路 |
| 专业 | 真实单位与精度、UTC 时间、可扫视的表格；不用插画和表情 |

## 太空科技方向谱

从这里挑三个，挑出来的三个在骨架、字体、色彩、主视觉上至多一项相同。每个方向都要说得出来自这个产品的理由。

| 方向 | 生成引擎（从什么事物出发） | 骨架 | 字体 | 色彩 | 主视觉 |
| --- | --- | --- | --- | --- | --- |
| **任务控制台 Mission** | 1960–70 年代休斯顿控制室、CRT 终端 | 多栏密集网格，主读数居中 | 等宽为主（JetBrains Mono / IBM Plex Mono） | 炭黑 + 琥珀，状态绿 / 红 | 一个超大倒计时或主读数 |
| **轨道蓝图 Blueprint** | 工程图纸、星图、轨道力学示意 | 左文右图或满屏图纸，大量标注线 | 窄无衬线 + 等宽标注 | 钴蓝底 + 白线，单色 | 用 SVG 画的轨道 / 剖面图 |
| **深空 Deepfield** | 哈勃 / JWST 深场照片、天文馆 | 极简，大留白，文字压在照片暗部 | 几何无衬线大字（Space Grotesk） | 近黑 + 离子白 + 一点紫 | 一张真实深空照片或行星边缘 |
| **全息 HUD** | 战斗机平显、头盔面罩 | 中心准星，信息贴四边 | 细等宽 + 极小标签 | 透明底上单色绿或青 | 准星、俯仰梯、雷达 |
| **太空竞赛 Retro** | 1960 年代 NASA 手册、苏联航天海报 | 海报式大标题 + 编号章节 | 粗几何无衬线 / 构成主义衬线 | 米白纸 + 红 + 海军蓝 | 版画质感的火箭或徽章 |
| **舱内材质 Habitat** | 空间站舱壁、宇航服织物、钛合金 | 模块化卡片像舱段对接 | 圆润无衬线 | 浅灰白 + 安全橙 | 实拍材质与模块剖面 |
| **地球观测 EO** | 卫星影像、伪彩色遥感 | 地图优先，工具栏浮在图上 | 中性无衬线 + 等宽坐标 | 由影像取色，界面中性 | 大幅卫星影像 |
| **星际拓荒 Frontier（NASA-punk）** | 游戏 Starfield 的界面：载人航天的白色舱体、涂装条、任务日志 | 星球占半屏，信息贴左侧一列，底部按键提示条 | 几何无衬线（Jost）+ 半窄无衬线读数（Barlow） | 石墨底 + 暖白，四色涂装条只做点缀 | 被引线标注的星球、刻度环 | 

注意：“全息 HUD”“深空”“任务控制台”很容易都做成“黑底 + 一种亮色”。同时选中其中两个时，至少一个要在骨架和色温上彻底拉开（例如琥珀暖色 vs 紫白冷色，密集网格 vs 大留白）。

### 拆解：Starfield（星际拓荒方向的标杆）

Bethesda 的美术团队把这套风格叫作 “NASA-punk”：比赛博朋克更落地，像真实载人航天往前推几十年。拆成能照着做的要素：

| 要素 | 它是什么样 | 为什么这样做 |
| --- | --- | --- |
| 选中态 | 列表里选中的那一行整行反白（暖白底、深色字），其余行是透明底上的白字 | 手柄操作没有鼠标指针，焦点必须一眼看到；反白比彩色高亮更“仪器” |
| 线 | 1px 暖白细线，端点常带一个小实心圆或短竖刻度；标注线从对象出发折一次再接文字 | 线代表“测量与连接”，端点说明它从哪里来、到哪里停 |
| 圆 | 扫描与菜单大量用圆：一圈短刻度 + 一段细弧；数据菜单以圆为中心放射排布 | 呼应星球、轨道和头盔面罩，圆就是这个世界的基本形 |
| 涂装条 | 宇航服、飞船和品牌上的多色横条（蓝、红、橙、金这一类） | 来自真实航天器和工装的识别色带，给冷色界面一点温度 |
| 字体 | 几何、圆润、偏宽的无衬线（原作用 Neubau Berlin 的 NB Architekt / NB Grotesk） | 工业产品铭牌的气质；玩家反馈原作字号偏小、长文本难读 |
| 底与面板 | 石墨色半透明面板压在星球或场景上，带模糊；几乎不用阴影和发光 | 让场景始终在背后可见，界面像头盔里的平显 |
| 按键提示 | 操作旁标着按键：“[E] 采集”“[R] 切换” | 告诉玩家怎么做，不只告诉玩家能做什么 |
| 首屏 | 黑色星空、一颗星球、左对齐的少量白字 | 克制到几乎只有标题，被批评过“太空”，也因此辨识度高 |

**留什么、换什么（网页落地时）：**

- 留：反白选中、带端点的引线、刻度环、暖白配石墨、半透明面板、四色涂装条只做点缀。
- 换：原作字号偏小、长文本难读，这里正文至少 15px；原作菜单层级深、导航绕，网页里主动作放在首屏、一次点击可达。
- 换：按键提示只给键盘真的能触发的动作，而且必须同时能点；触屏上隐藏按键标记，只保留按钮文字。
- 不碰：Starfield 和 Constellation 的标志、徽章，原作的专有字体文件和截图素材。用 Jost / Barlow 这类开源字体和自己画的线来表达同一种气质，不做成“像官方的页面”。

## 定色彩

- 先定底色温度：纯黑（#000）在 OLED 上好看，但大面积文字发虚；任务界面用略带色相的深色（#07090c、#0a1a3a）。
- 一个强调色只做一件事：动作，或关键读数。告警色（红）只给真正需要中止的状态。
- 发光（box-shadow / text-shadow）是强调的一种，和强调色同等稀缺；不给每张卡片加光晕。
- 状态不能只靠颜色：绿圆点 / 黄三角 / 红闪烁方块，加文字。
- 浅色方向（Retro、Habitat）同样成立。太空不等于黑底。

## 方向卡

每个方向写一张：

```text
方向名：
北极星：一句能指导取舍的体验意图（例：“像在控制室里盯着唯一一个会决定发射的数字”）
标杆与取舍：拆了谁，留了什么，换了什么
调性：能量 / 完成度 / 密度 / 分量 / 严肃度 各取值与依据
骨架：首屏主角是什么，放在哪
字体：展示 / 正文 / 数据 各用什么
色彩：底色、强调色、状态色（十六进制）
主视觉：靠什么（图、SVG、3D、数字本身）
装饰语言：最多两种（网格 / 角标 / 扫描线 / 噪点 / 光晕 / 星点）
让人记住的一刻：
```

## 差异检验

三张方向卡并排：骨架、字体、色彩、主视觉四栏里，任意两个方向最多一栏相同。把每个方向和拆过的标杆再并排看一次，确认不撞脸。

## 让人记住的一刻

只在一两处做到极致，其余保持安静。太空界面里好用的“时刻”：

- 倒计时归零的那一帧：数字变成 “LIFTOFF”，全屏只剩一条上升的轨迹线。
- 读数刷新：等宽数字逐位滚动，只有变化的那一位动。
- 提交表单变成“发送指令”：按钮显示上行链路进度，完成后回显“ACK 238 ms”。
- 滚动时行星从画面底部升起，地平线的大气光晕成为分区线。
